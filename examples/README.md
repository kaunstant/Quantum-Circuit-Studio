# Version 0.2 Examples

Every `.cpp` file in this directory is an independent program with its own `main()` and is built as a separate executable by CMake.

The examples include Bell and GHZ validation, circuit-library algorithms, reusable and hand-built Grover, reusable and hand-built Shor, VQE, and QAOA. Shared helpers are in `ExampleSupport.hpp`; console formatting is in `engine/console/StatePrinter.hpp`.
